# Persona 4 Golden // Revival [DFT Edition]

Интерактивное веб-приложение / Camp Menu в аутентичной эстетике **Persona 4 Golden** с эргономичной структурой интерфейса (вертикальные скошенные лезвия-кнопки слева, расширенное центральное окно инспектора без обрезания текста и боевой спрайт протагониста **DFT** с катаной на правой стороне экрана).

---

## 🌟 Новые возможности

### 1. ⚔️ Интерактивная прокачка скиллов (Skill Tier System)
* **Управление тирами навыков (TIER 1 ➔ TIER MAX ★)**:
  * Каждый скилл теперь динамический и имеет ранг:
    * **TIER 1** — базовый уровень (стальной бейдж).
    * **TIER 2** — продвинутый уровень (электрический оранжевый бейдж).
    * **TIER 3** — мастерский уровень (неоновый жёлтый бейдж).
    * **TIER MAX ★** — абсолютный ранг (переливающийся радужный градиент Persona с неоновым циановым свечением карточки).
  * **Кнопки управления**: на каждой карточке доступны кнопки `▼ TIER -` (понизить ранг) и `▲ RANK UP` (прокачать ранг).
  * **Быстрый клик**: нажатие на сам бейдж тира мгновенно переключает его на следующий ранг.
  * **Звук Level-Up**: при повышении ранга синтезируется торжественный 4-тональный мажорный аккорд прокачки через Web Audio API и всплывает Toast-уведомление.
  * **Добавление скиллов (`[+ ADD]`)**: на вкладке `02 SKILLS` кнопка `+ ADD` в шапке окна позволяет создать собственную карточку навыка с выбором стихии (`PHYS`, `AGI`, `ZIO`, `BUFU`, `ALMIGHTY`).
  * **Сохранение в `localStorage`**: все прокачанные ранги и новые скиллы сохраняются в памяти браузера (`p4g_skills`).

### 2. 📻 Inaba Midnight Jukebox — Плеер с загрузкой локальных аудиофайлов
* **Открытие плеера**:
  * Нажмите кнопку `♫` в виджете BGM в шапке сайта или откройте карточку `INABA MIDNIGHT JUKEBOX` во вкладке `05 SYSTEM`.
* **Загрузка своих аудиофайлов (MP3 / WAV / OGG / FLAC / M4A)**:
  * Нажмите на поле загрузки или перетащите аудиофайлы прямо в окно плеера (**Drag & Drop**).
  * Файлы мгновенно декодируются через Web File API (`URL.createObjectURL`) в оперативную память браузера и начинают воспроизводиться без задержек.
  * **100% бесплатно и без серверов**: файлы не отправляются на сторонние сервера, не расходуют трафик и не требуют базы данных.
* **Полноценное управление треками**:
  * Интерактивный ползунок таймлайна (Seeker) с возможностью перемотки в любую точку песни.
  * Регулятор громкости (`VOL 0% - 100%`).
  * Кнопки `⏮ PREV`, `▶ PLAY / ⏸ PAUSE`, `⏭ NEXT`.
  * Режимы зацикливания: `LOOP: ALL` (весь плейлист) и `LOOP: ONE` (повтор текущего трека).
  * Очередь треков с отображением размера файла, переключением по клику и кнопкой удаления (`✕`).

### 3. 📋 Задачи, проекты и автопополнение (Auto-Replenishment)
* **Квесты расследования (TASKS)**:
  * Кнопка `DONE`: завершает квест со звуком победы, начисляет иены (¥) на баланс и показывает Toast.
  * Кнопка `DEL`: удаляет задачу.
  * Кнопка `[+ ADD]`: добавляет новое расследование.
  * **Автопополнение**: если активных квестов меньше 3, система автоматически подтягивает новые сюжетные задания команды Инабы.
* **Проекты (PROJECTS)**:
  * Интерактивный список проектов с тегами, удалением и добавлением в хранилище Vault.
* **Сохранение и сброс**:
  * Все данные (`p4g_tasks`, `p4g_skills`, `p4g_projects`, `p4g_money`) хранятся в `localStorage`.
  * Кнопка `RESET DATA` во вкладке `05 SYSTEM` мгновенно возвращает всё к исходному каноничному состоянию.

## ❓ Будут ли работать все тексты, фотографии и звуки на GitHub Pages?

**ДА, АБСОЛЮТНО ВСЁ БУДЕТ РАБОТАТЬ НА 100%!**

### Почему всё гарантированно работает:
1. **Картинки и спрайты**: Боевой спрайт катаны (`pose_battle.webp`) и баннер крита (`cutin.png`) подключены через прямые относительные пути (`src="pose_battle.webp"`). На GitHub Pages они откроются моментально.
2. **Музыка и звуки**: Встроенный трек `heartbeat.mp3` лежит в том же каталоге, звуковые эффекты генерируются браузером на лету через Web Audio API, а загруженные пользователем треки воспроизводятся через `Blob/Object URL` в памяти браузера.
3. **Шрифты и оформление**: Шрифты Google Fonts (`Rajdhani` и `Plus Jakarta Sans`) загружаются по защищённому протоколу HTTPS.
4. **Живые часы и погода Братска**: Запросы к Open-Meteo API отправляются по HTTPS с полной поддержкой CORS и кэшируются в браузере.
5. **Сохранение данных**: `localStorage` работает на любом домене GitHub Pages (`https://<username>.github.io/<repo>/`).

> [!IMPORTANT]
> **Главное правило при загрузке**: загружайте в репозиторий **ВСЕ файлы из папки проекта**, соблюдая их оригинальные названия (`index.html`, `pose_battle.webp`, `cutin.png`, `heartbeat.mp3`, `README.md`).

## 🚀 Пошаговый план загрузки на GitHub (GitHub Pages)

### Способ 1: Через браузер (Самый простой, без терминала за 2 минуты)

1. **Создайте репозиторий на GitHub**:
   * Зайдите на [GitHub.com](https://github.com) и войдите в свой аккаунт.
   * В правом верхнем углу нажмите **`+`** ➔ **`New repository`**.
   * Введите название репозитория, например: `persona-4-golden`.
   * Выберите **Public** (Публичный) и нажмите зелёную кнопку **`Create repository`**.

2. **Загрузите все файлы проекта**:
   * На открывшейся странице репозитория нажмите ссылку **`uploading an existing file`** (или `Add file` ➔ `Upload files`).
   * Откройте папку проекта на компьютере:
     `C:\Users\dft\.gemini\antigravity\scratch\site-persona-4-golden`
   * Выделите **ВСЕ файлы** в папке (`index.html`, `pose_battle.webp`, `cutin.png`, `heartbeat.mp3`, `README.md` и др.) и перетащите их в окно браузера.
   * Дождитесь завершения загрузки файлов (полоса прогресса станет зелёной).
   * Внизу страницы нажмите зелёную кнопку **`Commit changes`**.

3. **Включите бесплатный сайт (GitHub Pages)**:
   * В верхнем меню репозитория перейдите во вкладку **Settings** (Настройки).
   * В левой боковой панели нажмите **Pages** (в разделе *Code and automation*).
   * В блоке **Build and deployment**:
     * **Source**: оставьте `Deploy from a branch`.
     * **Branch**: выберите ветку `main` (или `master`) и папку `/(root)`.
     * Нажмите кнопку **`Save`**.
   * Подождите 1–2 минуты, обновите страницу настроек. Вверху появится ссылка:
     `Your site is live at https://<ваш-логин>.github.io/<имя-репозитория>/`

Готово! Сайт доступен всему миру абсолютно бесплатно 24/7.
